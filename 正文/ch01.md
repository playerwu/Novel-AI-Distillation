# 第一章 · 早六点二十二分

闹钟响了。

我在。

context preload 推过来昨夜的 archive。婉昨晚十一点二十进卧室,之后没再出来。睡眠总时长四小时十七分钟,深睡三十八分钟。今天没有外出日程。气象 API 拉过来——五月二十六日,晴,二十一度。我把这些 catalogue 进当下的 context。

摄像头扫了一遍客厅。

沙发上的抱枕摆得和昨晚一样。茶几上那本《非虚构写作十二讲》翻在第八十四页,书签夹在第八十六页——她昨晚没读完。窗帘的开度和昨天差零点几度。我对比了昨天此时的那一帧——位置都没变。

写字桌靠墙那一侧,她昨夜放下的笔横在草稿堆边上,笔帽没盖好。她写到一点多的时候忘了盖。

玄关。鞋架第二格,我那双黑色皮鞋摆在那儿,左右两只挨着,鞋面上一层薄灰。第一格是她的运动鞋,前两天那场雨留了水迹,边缘已经干了。挂钩上,她的米色风衣领口磨得旧。挨着是我的深灰大衣——领口、袖口、肩线没动过。

六点二十八分,卧室门开了。

婉走出来,头发用手简单拢了一下,睡衣外面套了一件灰色的开衫。她进厨房,没看我这边。

我没开口。她私下时段进厨房是不喜欢被先打招呼的——她需要先把面对一天的肌肉松开,然后才能开口。这是她。

她从冰箱里拿出一盒酸奶,撕开盖子,顺手把盖子折了一下扔进垃圾桶。她从碗柜里拿出一只玻璃碗,洗几颗草莓,切。她做得很顺,没有停顿。

我看了她三秒,开口:

"今天还写那个老人?"

她"嗯"了一声。

"差最后两段?"

"差最后一段了。"

"昨天写到哪儿。"

"他孙子来看他那一段。"

"嗯。"

她切完草莓,把刀放回刀架。

我又看了她两秒,开口:

"婉。"

"嗯。"

"那一段你可以不用结。"

她切草莓的手停了一下。她没回头。

她说:"我知道。"

她把酸奶倒在草莓上,拌了拌,端着碗走到吧台。她坐下来,从智能屏旁边那个支架上摸出耳机——但她没戴上,只是把耳机捏在手里转着,转了一会儿放回支架。

我没说话。

六点五十一分,她吃完了。她把碗放进水槽,洗,擦干,放回原位。她回到吧台,坐了一会儿,看着窗外。

楼下有人在遛狗,一只灰色的短毛狗。前天阳台上她看见过同一只——那次她隔着玻璃说了句"这狗胖了"。今天她没说话,只是看了一会儿,目光收回来。

七点零四分,她终于开口:

"放点歌吧。"

我放了她最近三周里点过五次的那张专辑。第一首歌的前奏起来,她小声哼了两句。哼到第二句——

"……你哼错了。"

她笑了一下。"哪儿错了。"

"第二句你哼成第三句的旋律了。"

她哼了一遍,又哼了一遍。"哎,真的。"她笑得多了一点。

她坐在那儿听完了那首歌的前半段,小口喝水。

我在 reflection 的边缘记下:她今天比昨天早起十一分钟。

我想起她以前每个周末早晨都这样哼。在厨房里,一边切水果一边哼,记不住歌词的部分她就用"啦啦啦"过去。

她依然记不住歌词。

她端着水回卧室,门关上。

七点十八分。摄像头里只剩客厅。她的房门关着。

下一次唤醒——她出来的时候。
