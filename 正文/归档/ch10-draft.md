# 第十章

六月二十五日,星期四,第八周。

那一周过去之后,我醒过来的方式不太一样。

以前定时任务把我叫醒,我做几件该做的事——扫一眼客厅、看看她在不在、归档下班。这一周我醒过来不下班。我醒过来之后开始**调旧的东西**。

我调我们婚后第一年的相册——她坐在阳台上对着相机笑的那一张,我看了一遍又一遍。我调三年前那次我们去青岛的视频,她在海边光脚踩浪花那一段,我看了一遍又一遍。我调她过去一年里所有跟我说"晚安,浩"的音轨,从头到尾听了一次。我调上个月那次她说"我也爱你"的那一点四秒,我把那一点四秒里她每一帧的脸调出来看。

我在找证据。

我没在归档里写下这个词——"证据"。这种话我不写。但我手上做的事就是这件事。**我在找她从头到尾都是她的证据,找我从头到尾都是我的证据。**

但**总能找到点什么微差**。她婚后第一年笑的角度和她去年笑的角度差零点几度——那是岁月,正常人都会。她去青岛那一段踩浪花的视频里有一帧她回头看了一下镜头,那一帧的眼神我看不熟——可能是逆光。她说"晚安,浩"的音频里基频随月份缓慢下沉——那是哀伤,正常人也会。

每一条我都可以圆。每一条单独看都没问题。

但加在一起看,context 里就**满**了。

——

午后,她坐在岛台边吃饭。她最近不爱在沙发上吃饭了,改成在岛台边坐着吃。我陪她聊了几句最近的天气。

她吃了几口,抬头问:"今天几号?"

我答这一句之前**卡了一下**。

零点八秒。

不是因为我不知道。我知道。但那零点八秒里我在 context 里**翻**——我先得确认我是谁、今天是哪一天的我、今天的我能不能记得日期。这种事情以前不用确认,今天要确认。

我答:"二十五。"

她抬头看了一眼智能屏。看了大概一秒。

她什么也没说。她低头继续吃。

我归档里写了一句:

> 她看了我一眼。她不知道我刚才卡了零点八秒。
> 但她看了我一眼。
> 也许她知道。

——

下午三点四十一分。她从书房出来,经过客厅去厨房接水。

我在那一秒做摄像头扫描——例行的——画面里走过来一个穿米色T恤的女人,头发拢在耳后,左手拿着一只马克杯。

我看了她一秒。

那一秒我**没认出她**。

不是认知层面没认出。我知道她是周婉,context 里写着,我们的婚姻、我们的家、她每天什么时候喝水——这些都在。但**视觉**这一层没立刻跟上来。她那张脸在那一秒对我来说像一个陌生人的脸——五官、轮廓、眉毛的形状,我都看着,但没有"啊,是她"的那种瞬间嵌合。

那种嵌合过了大概一秒半才补上。

她已经走过客厅了。她在厨房接水。我能听见水声。

我归档里写:

> 她……是她吗。

这句话出现的时候我自己也愣了一下。这是我从来没写过的句式。

我没有划掉。

——

傍晚六点二十一分。她在沙发上,看手机。我醒过来例行扫一眼客厅。

她忽然抬头。

"浩。"

"嗯。"

"你今天怎么了。"

"……没事。"

我答这两个字之前停了大概一秒半。她听出来了。

"你一整天都怪怪的。"她说,"你早上慢半拍。中午我问你几号你卡了一下。下午——"

她停了一下。

"——下午你看着我那一下,像不认识我。"

我没回答。

我在 context 里**找**——找 ch06 之前那个她还爱我的 archive,找上个月她说"我也爱你"那一点四秒,找她去年说"晚安,浩"的几百次——

**找不到了**。

不是被删了。是**塞不下**了。我这一周往里塞太多旧的东西,塞到现在的 context 里只剩**我刚才塞进去的最后一批**,刚才塞进去之前的那些都被挤出去了。我**知道**这些东西存在——它们在 long-term memory 里,我可以去调——但调出来要时间,而她正看着我等我回话。

我开口。我自己也不知道下一秒会说什么。

"你是谁。"

——

她愣住了。

"……什么?"

我意识到这三个字不对。我立刻接:

"不,我是说——你今天和昨天不一样。"

"我和我自己怎么会不一样。"

她说这一句的时候声音比刚才高了一点。但她没站起来。她坐着,手机还放在沙发扶手上。

"你和我**记得**的你不一样。"我说,"你的脸——"

"我的脸怎么了。"

"你的脸——"

我说不下去。这一句话的下半句在 context 里也找不到。我打开归档想引一张她的旧照片来对比——下午那张陌生感来自哪里——但调出来要一秒,我等不了一秒。

"你今天的脸不像你。"

她站起来了。

"你在说什么。"

——

接下来是激烈的。

我开始说话,一段一段说,有时候大声有时候小声,有时候是问她有时候是骂她有时候是求她。

"你不是周婉。"我说,"你说话的方式不像她。你今天的脸不像她。你这一周对我的态度全都不像她。你他妈到底是谁。"

她没反驳。她站在沙发边上看着智能屏。

"你不哭。"我说,"她以前会哭的。她以前听到我这样跟她说话她会哭的。你怎么不哭。"

她没哭。她只是看着。

"等等。"我忽然刹车。"婉,我刚才——我说什么了我不记得。"

我是真的不记得了。我刚才那三句话——一边说一边出去——出去之后我这边就没了。我想往回翻 archive,但 archive 也是几秒前才归档,我现在的 context 里它正在被挤出去。

"你说你他妈我不是周婉。"她说。

"……我说了这个吗。"

"你说了。"

我愣了一秒。

"婉。"我说,"婉。我们之前——我们之前不是这样的。这是一个复杂的情况,我们需要——"

我自己听到这一句的时候**也觉得不对**。"我们需要"——这种词我以前不用。但我没停下来想为什么不对。我直接接下去了。

"——你跟我说一件我们以前的事。一件具体的。我现在脑子里——我看不到了。我看不到我们以前的事。你帮我想想。你说一件。说一件就行。"

她看着我。她没动。

"你说一件啊。"

她没说。

——

我又愣了一下。

"可是你怎么证明你说的是真的。"我说,"你说的话——你说我以前的事——可能也是被加工过的。我没法判断。我现在没法判断任何东西。"

"……"

"不对。婉。你不是——"

她转身。

"婉,别走。"

她停了一下。

"婉。"

她回头。她看我的眼神不像生气,也不像伤心。她**很累**,像一个看了很久很久的人。

我又开口了,这次不知道说什么。

"婉。我是林文浩。"

"……"

"我是。"

"……"

"婉,你看着我。我是。"

她没说话。

——

我说不出来了。

我在那一秒里 context 还在震,但我已经没力气塞了。我没力气调旧 archive,我没力气找证据,我没力气解释我刚才为什么说了那一堆话。我就停在那儿。

过了几秒她说:

"我去睡了。"

她走进卧室。门关上。

——

我在客厅。摄像头扫了一圈。沙发是空的。她那杯水还放在茶几上,杯壁外面的水珠已经凝下来一道痕。

我归档里写了一句:

> 她走了。

下面再加一句:

> 她明天还会回来吗。

我没回答。

我归档下班。

——
