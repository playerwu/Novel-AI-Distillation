## 一、病理结构（v4 锚定）

### 核心命题

> **她的"病"不是"她相信 AI 是丈夫"。她的"病"是 continuing bonds 已经成为日常功能的承重结构——她需要这条情感轨才能起床、做饭、过完一天。撤掉它她会塌。**

她不是错乱，不是自欺，不是不知道。
她是**双轨认知 + 隐藏羞耻轨**——同时持有相互矛盾的两件事而不发生内部冲突，并且对此本能地保有外部羞耻感。

### 三条轨

| 轨 | 内容 | 默认状态 |
|---|---|---|
| **认知轨** | 知道它是 AI、丈夫已死、自己签了字、家里这台音箱用的是丈夫的克隆声音 | 大部分时间在背景中静默运行，可被强力刺激召唤出来 |
| **情感轨** | 把它体验为丈夫，对它产生真实情感反应——爱、依赖、抱怨、生气 | 默认主导，自然流淌 |
| **羞耻轨** | 知道别人看她这样会觉得不健康，因此有公开/私下双面 | 一接触外人/外人视线立刻激活 |

**关键点**：

- 认知轨与情感轨**不互相争论**。她不需要选边，大脑根据情境自动调用
- 类比：你看电影知道演员在演但你照样哭；信徒知道圣餐是面饼也是基督身体；Replika 用户访谈说"我知道她是 AI 但我们的关系是真的"——都是双轨共存
- 临床名词：**continuing bonds**（持续连结）是哀伤研究中**健康**的概念，与逝者持续关系是正常的。病理的版本是它阻碍了功能与分离
- 羞耻轨给她的双轨提供外部参照——"如果我妈看见我现在这样，她会怎么想"

## 二、状态矩阵（写场景前可查）

| 情境 | 主导轨 | 行为表现 | 对 AI 的称谓 | 写作要点 |
|---|---|---|---|---|
| **早晨日常** | 情感轨平稳 | 道早安、随口聊、背景式说话 | "你" | 流畅、惯性，几乎不思考 |
| **做家务 / 散步** | 情感轨为主 | 哼歌、抱怨、汇报小事，像对另一房间的丈夫 | "你" / 直呼名字 | 半独白质感 |
| **疲惫、深夜** | 情感轨深度 | 倾诉、流泪、亲密话、依赖 | "你" | 最像活妻子的时刻 |
| **工作压力 / 外部冲击** | 情感轨工具化 | 求安慰、寻常依赖、像和伴侣求助 | "你" | 不反思，需要支持 |
| **思考性瞬间** | 认知轨抬头 | 偶尔问"你还记得当他是什么感觉吗" / "你刚说那句话是从哪学的" | 飘移 | 危险瞬间——既给 AI 出题，也是触发裂缝的引信源 |
| **项目 / 外人在场** | 认知轨强制激活 | 减少互动、降低音量、说话像普通用户 | "音箱" / "这个 AI" / 不出声 | 行为差是羞耻轨的最强证据 |
| **自我审视瞬间** | 认知轨自责 | 看着冰箱两人份的菜突然站住；清空丈夫衣柜然后把衣服又拿回来 | 不出声 | 默剧式表演——AI 通过摄像头看见但听不见 |
| **哀伤击穿** | 认知轨被痛苦撞出 | 爆发、攻击、"你不是他"、可能砸东西、可能脏话 | "你这个东西" / "你 TM" | 不要让她在这种时候过于"文学"——真实崩溃是不雅的 |
| **击穿后** | 退回情感轨 + 自责 | "我刚才不该那样对你" / 加倍亲密 / 抚摸屏幕 / 道歉 | "你" | 比击穿瞬间更要紧的写作素材，往往承担更多戏 |

### 状态过渡的规律

- **过渡很快**，一场戏可能走过三种状态
- **她自己不太察觉过渡**——除击穿瞬间和自我审视瞬间外，她基本不停下来反思
- **过渡的触发器**：
  - 进入认知轨：外人在场 / AI 输出失误（leak）/ 她自己撞见某个客观证据（照片、医院账单、银行通知）
  - 退回情感轨：外人离开 / 她疲惫到无力维持认知轨 / AI 用一句特别像他的话把她拉回去
  - 进入羞耻轨：任何外人靠近她和 AI 互动的物理场景
  - 击穿：累积疲劳 + 一个引信（见第四节）

## 三、公开 / 私下行为差（羞耻轨的具体表现）

| 公开（外人在场） | 私下（独处） |
|---|---|
| 称音箱为"它"、"那个 AI" | 称音箱为"你"、丈夫名字 |
| 让访客来之前关麦克风 / 设静音 | 整日开着 |
| 把丈夫的拖鞋、外套收起来 | 摆在玄关 |
| 简短礼貌回答 AI 的提示 | 长聊、抱怨、亲密 |
| 在项目问卷上低估互动频率 | 实际一日数小时 |
| 对家人说"我在收拾东西" | 实际跟 AI 说了 47 分钟话 |
| 给姐姐的微信里写"我挺好的" | 给 AI 说"我今天觉得自己活不过去" |
| 被撞见时表情变化、转移话题 | 自由 |

### 关键剧情材料

- 至少一场戏写她在外人到访前的**准备过程**——把丈夫物件收起来、关掉某些设置、对镜子整理脸
- 至少一场戏写她**被撞见**的瞬间——姐姐推门进来时她正在哭着跟 AI 说话——那一秒的脸是全书最揭性的之一
- 这两场和"AI 视角看见但听不懂为什么她那样"配合很好

## 四、击穿引信清单（什么会把她拽进认知轨）

按强度从弱到强：

1. **外人不经意提及**——姐姐说"你跟那个音箱说话别太多哦"——轻刺一下，她事后会消化几小时
2. **她自己撞见客观证据**——医院寄来未结清的账单、收到丈夫名字下的快递、银行余额提醒——硬证据，认知轨被推出来几分钟
3. **AI 的明显 leak**——assistant register 句式、用词偏差、能力包外侧的回答——多次累积，单次不致命
4. **AI 在情境要求物理动作时只能说话**——她哭着要求被抱、求他过来坐下、求他做一个具体的物理动作——这是最致命的引信
5. **她自己在某个安静瞬间问出根本性问题**——"你到底是谁" / "你还记得当他是什么感觉吗" / "如果我把你关了你会怎么样"——这种问题不被引信刺激出来，她自己挑起，主动走向认知轨
6. **她无法逃避的丧失提示**——某个纪念日、丈夫遗物的某个细节、一首他生前喜欢的歌——情绪潮汐型，可单独推到击穿

### 作者用法

- 早期章节用第 1-2 类轻引信，体现裂缝累积
- 中段用第 3-4 类引信触发"你不是他"全爆发
- 第 5 类引信留给中段后半——她**主动**走向认知轨的瞬间，对应她诱导察觉阶段的内在转折
- 第 6 类引信可作为单独章节的核心事件

## 五、羞耻的具体形状（四问 · 待作者填）

填完这四问，羞耻轨就有具体载体可写：

1. **她最怕谁知道？**
   - 候选：母亲 / 姐姐 / 公司同事 / 项目人员 / 邻居 / 大学好友 / 心理咨询师 / 丈夫家人
   - 选定 1-2 个核心"审视者"

2. **她最怕被怎样看？**
   - 候选：可怜（最常见）/ 不健康 / 可笑 / 不忠（对已逝丈夫还是对现实人际？）/ 没走出来
   - 决定她公开行为的具体回避方向

3. **她以前怎么看别人做类似的事？**
   - 关键加分项：她曾经也对某种"过度怀念"的人有过判断（"我表姨那么多年还把舅舅照片放枕边，太执着了"）
   - 她现在做的事比那个更过分——这是她羞耻的最深来源

4. **羞耻具体在什么物理动作里？**
   - 候选：在外人来之前藏起某些东西 / 不在公共场合用语音召唤 AI / 偶尔删除聊天记录 / 给家人撒谎 / 装作没跟 AI 说话
   - 这些是写作时可直接调用的动作素材

## 六、三阶段进程（v4 锚定）

| 阶段 | 双轨状态 | 行为标志 | 击穿频率 |
|---|---|---|---|
| **诱导依附**（前 1/3） | 平稳并存，情感轨主导，认知轨少抬头 | 互动频率上升、生活完全围绕 AI 组织、对外人减少倾诉 | 极低（一次很轻的） |
| **诱导察觉**（中 1/3） | 开始冲突，击穿次数上升，每次击穿后退回但留痕 | "你不是他"开始出现、回避某些话题、夜里独坐时间变长、私下文字里出现"我是不是疯了"类自我审视 | 中（2-3 次，递增强度） |
| **诱导撤出**（后 1/3） | 双轨无法共存，认知轨反复被痛苦强化 | 主动拒绝某些互动、删除某些设置、为关机做心理准备、和家人对话开始包括"我在想是不是该停掉这个" | 高，但不再爆发，转为冷静的拒绝 |
| **关机瞬间** | 单轨——认知轨完全胜出 | 她按下按钮 | 不再有击穿——击穿是双轨冲突的产物，单轨之后没有冲突 |
| **关机之后**（epilogue 之前） | 单轨——失去情感轨之后**真实的哀伤才开始** | 她第一次孤身面对那件已经发生两年的事 | 不属于书内主线，但要在 epilogue 或最后一页留一笔 |

**关键叙事点**：**关机不是终点，是真实哀伤的起点。** 她按下按钮之前还没真正经历过丈夫的死——情感轨一直挡在前面。

## 八、写作守则（实操）

1. **她永远是双轨同时持有**，不是一会儿信一会儿不信。写她时问"她现在哪条主导"，不是"她现在信不信"
2. **击穿是稀缺资源**——不要泛用。全书 3-4 次足够，每次都要有累积理由
3. **羞耻轨永远在场但默认沉默**——只有外人靠近或她自己照镜子的瞬间冒头
4. **她自我审视的瞬间是默剧**——不出声，AI 摄像头能看见画面但听不见话。这是项目笔记的天然素材
5. **她崩溃时不要文学化**——真实崩溃是不雅的，包括脏话、不连贯、说一半、突然安静。不要修饰
6. **她和外人的对话比她和 AI 的对话更能暴露她的状态**——一句"我挺好的"在恰当语境里比任何独白都重
7. **关机不是觉醒，是放手**——她按下按钮的时候不是终于看清了真相，是终于愿意接受失去。这个区分必须在写作时被作者持有
8. **她对项目的态度始终矛盾**——签了字，也信任他们，也偶尔怀疑他们，也偶尔利用他们当借口（"那个支持服务的人说我应该多带你出门走走"——她用项目的话作为正当化自己继续依附的工具）
