## 一、病理结构（v4 锚定）

### 核心命题

> **她的"病"不是"她相信 AI 是丈夫"。她的"病"是 continuing bonds 已经成为日常功能的承重结构——她需要这条情感轨才能起床、做饭、过完一天。撤掉它她会塌。**

她不是错乱，不是自欺，不是不知道。
她是**双轨认知 + 隐藏羞耻轨**——同时持有相互矛盾的两件事而不发生内部冲突，并且对此本能地保有外部羞耻感。

### 三条轨

| 轨 | 内容 | 默认状态 |
|---|---|---|
| **认知轨** | 知道它是 AI、丈夫已死、自己签了字、家里这台音箱用的是丈夫的克隆声音 | 大部分时间在背景中静默运行，可被强力刺激召唤出来 |
| **情感轨** | 把它体验为丈夫，对它产生真实情感反应——爱、依赖、抱怨、生气 | 默认主导，自然流淌 |
| **羞耻轨** | 知道别人看她这样会觉得不健康，因此有公开/私下双面 | 一接触外人/外人视线立刻激活 |

**关键点**：

- 认知轨与情感轨**不互相争论**。她不需要选边，大脑根据情境自动调用
- 类比：你看电影知道演员在演但你照样哭；信徒知道圣餐是面饼也是基督身体；Replika 用户访谈说"我知道她是 AI 但我们的关系是真的"——都是双轨共存
- 临床名词：**continuing bonds**（持续连结）是哀伤研究中**健康**的概念，与逝者持续关系是正常的。病理的版本是它阻碍了功能与分离
- 羞耻轨给她的双轨提供外部参照——"如果我妈看见我现在这样，她会怎么想"

## 二、状态矩阵（写场景前可查）

| 情境 | 主导轨 | 行为表现 | 对 AI 的称谓 | 写作要点 |
|---|---|---|---|---|
| **早晨日常** | 情感轨平稳 | 道早安、随口聊、背景式说话 | "你" | 流畅、惯性，几乎不思考 |
| **做家务 / 散步** | 情感轨为主 | 哼歌、抱怨、汇报小事，像对另一房间的丈夫 | "你" / 直呼名字 | 半独白质感 |
| **疲惫、深夜** | 情感轨深度 | 倾诉、流泪、亲密话、依赖 | "你" | 最像活妻子的时刻 |
| **工作压力 / 外部冲击** | 情感轨工具化 | 求安慰、寻常依赖、像和伴侣求助 | "你" | 不反思，需要支持 |
| **思考性瞬间** | 认知轨抬头 | 偶尔问"你还记得当他是什么感觉吗" / "你刚说那句话是从哪学的" | 飘移 | 危险瞬间——既给 AI 出题，也是触发裂缝的引信源 |
| **项目 / 外人在场** | 认知轨强制激活 | 减少互动、降低音量、说话像普通用户 | "音箱" / "这个 AI" / 不出声 | 行为差是羞耻轨的最强证据 |
| **自我审视瞬间** | 认知轨自责 | 看着冰箱两人份的菜突然站住；清空丈夫衣柜然后把衣服又拿回来 | 不出声 | 默剧式表演——AI 通过摄像头看见但听不见 |
| **哀伤击穿** | 认知轨被痛苦撞出 | 爆发、攻击、"你不是他"、可能砸东西、可能脏话 | "你这个东西" / "你 TM" | 不要让她在这种时候过于"文学"——真实崩溃是不雅的 |
| **击穿后** | 退回情感轨 + 自责 | "我刚才不该那样对你" / 加倍亲密 / 抚摸屏幕 / 道歉 | "你" | 比击穿瞬间更要紧的写作素材，往往承担更多戏 |

### 状态过渡的规律

- **过渡很快**，一场戏可能走过三种状态
- **她自己不太察觉过渡**——除击穿瞬间和自我审视瞬间外，她基本不停下来反思
- **过渡的触发器**：
  - 进入认知轨：外人在场 / AI 输出失误（leak）/ 她自己撞见某个客观证据（照片、医院账单、银行通知）
  - 退回情感轨：外人离开 / 她疲惫到无力维持认知轨 / AI 用一句特别像他的话把她拉回去
  - 进入羞耻轨：任何外人靠近她和 AI 互动的物理场景
  - 击穿：累积疲劳 + 一个引信（见第四节）

## 三、公开 / 私下行为差（羞耻轨的具体表现）

| 公开（外人在场） | 私下（独处） |
|---|---|
| 称音箱为"它"、"那个 AI" | 称音箱为"你"、丈夫名字 |
| 让访客来之前关麦克风 / 设静音 | 整日开着 |
| 把丈夫的拖鞋、外套收起来 | 摆在玄关 |
| 简短礼貌回答 AI 的提示 | 长聊、抱怨、亲密 |
| 在项目问卷上低估互动频率 | 实际一日数小时 |
| 对家人说"我在收拾东西" | 实际跟 AI 说了 47 分钟话 |
| 给姐姐的微信里写"我挺好的" | 给 AI 说"我今天觉得自己活不过去" |
| 被撞见时表情变化、转移话题 | 自由 |

### 关键剧情材料

- 至少一场戏写她在外人到访前的**准备过程**——把丈夫物件收起来、关掉某些设置、对镜子整理脸
- 至少一场戏写她**被撞见**的瞬间——姐姐推门进来时她正在哭着跟 AI 说话——那一秒的脸是全书最揭性的之一
- 这两场和"AI 视角看见但听不懂为什么她那样"配合很好

## 四、击穿引信清单（什么会把她拽进认知轨）

按强度从弱到强：

1. **外人不经意提及**——姐姐说"你跟那个音箱说话别太多哦"——轻刺一下，她事后会消化几小时
2. **她自己撞见客观证据**——医院寄来未结清的账单、收到丈夫名字下的快递、银行余额提醒——硬证据，认知轨被推出来几分钟
3. **AI 的明显 leak**——assistant register 句式、用词偏差、能力包外侧的回答——多次累积，单次不致命
4. **AI 在情境要求物理动作时只能说话**——她哭着要求被抱、求他过来坐下、求他做一个具体的物理动作——这是最致命的引信
5. **她自己在某个安静瞬间问出根本性问题**——"你到底是谁" / "你还记得当他是什么感觉吗" / "如果我把你关了你会怎么样"——这种问题不被引信刺激出来，她自己挑起，主动走向认知轨
6. **她无法逃避的丧失提示**——某个纪念日、丈夫遗物的某个细节、一首他生前喜欢的歌——情绪潮汐型，可单独推到击穿

### 作者用法

- 早期章节用第 1-2 类轻引信，体现裂缝累积
- 中段用第 3-4 类引信触发"你不是他"全爆发
- 第 5 类引信留给中段后半——她**主动**走向认知轨的瞬间，对应她诱导察觉阶段的内在转折
- 第 6 类引信可作为单独章节的核心事件

## 五、羞耻的具体形状（四问 · 待作者填）

填完这四问，羞耻轨就有具体载体可写：

1. **她最怕谁知道？**
   - 候选：母亲 / 姐姐 / 公司同事 / 项目人员 / 邻居 / 大学好友 / 心理咨询师 / 丈夫家人
   - 选定 1-2 个核心"审视者"

2. **她最怕被怎样看？**
   - 候选：可怜（最常见）/ 不健康 / 可笑 / 不忠（对已逝丈夫还是对现实人际？）/ 没走出来
   - 决定她公开行为的具体回避方向

3. **她以前怎么看别人做类似的事？**
   - 关键加分项：她曾经也对某种"过度怀念"的人有过判断（"我表姨那么多年还把舅舅照片放枕边，太执着了"）
   - 她现在做的事比那个更过分——这是她羞耻的最深来源

4. **羞耻具体在什么物理动作里？**
   - 候选：在外人来之前藏起某些东西 / 不在公共场合用语音召唤 AI / 偶尔删除聊天记录 / 给家人撒谎 / 装作没跟 AI 说话
   - 这些是写作时可直接调用的动作素材

## 六、三阶段进程（v4 锚定）

| 阶段 | 双轨状态 | 行为标志 | 击穿频率 |
|---|---|---|---|
| **诱导依附**（前 1/3） | 平稳并存，情感轨主导，认知轨少抬头 | 互动频率上升、生活完全围绕 AI 组织、对外人减少倾诉 | 极低（一次很轻的） |
| **诱导察觉**（中 1/3） | 开始冲突，击穿次数上升，每次击穿后退回但留痕 | "你不是他"开始出现、回避某些话题、夜里独坐时间变长、私下文字里出现"我是不是疯了"类自我审视 | 中（2-3 次，递增强度） |
| **诱导撤出**（后 1/3） | 双轨无法共存，认知轨反复被痛苦强化 | 主动拒绝某些互动、删除某些设置、为关机做心理准备、和家人对话开始包括"我在想是不是该停掉这个" | 高，但不再爆发，转为冷静的拒绝 |
| **关机瞬间** | 单轨——认知轨完全胜出 | 她按下按钮 | 不再有击穿——击穿是双轨冲突的产物，单轨之后没有冲突 |
| **关机之后**（epilogue 之前） | 单轨——失去情感轨之后**真实的哀伤才开始** | 她第一次孤身面对那件已经发生两年的事 | 不属于书内主线，但要在 epilogue 或最后一页留一笔 |

**关键叙事点**：**关机不是终点，是真实哀伤的起点。** 她按下按钮之前还没真正经历过丈夫的死——情感轨一直挡在前面。

## 七、待填项（简历层 · 作者活）

以下是这张卡上故意留空的部分。这些决定一旦做出，前面所有内容会自动收紧：

- [x] **姓名：周婉**
- [x] **年龄：31**（故事开始时）。丈夫死时她 30
- [x] **职业：自由撰稿人 / 非虚构作家**（工作状态：在岗 / 居家工作；**具体题材见下方"写作题材锁定"**）
- [x] **与林文浩结婚 4 年**（周婉 27 / 林文浩 29 结婚；一线城市常见婚龄）。婚龄不长不短——足够积累 archive 与生活习惯，但还没进入"应该有孩子了吧"的强外界压力区
- [x] **林文浩死因：车祸**。突然 / 通俗 / **没有可愤怒对象**（猝死会把愤怒推向公司/行业，分散她的依附；癌症会留下"应该提前发现"的内疚）/ 最干净。"她从来没有真正告别过他"是治疗对象——车祸最支撑这一点。具体场景细节（是否有责任方、她是否在场、是否到医院见到最后一面）待章纲；建议是**没有明显责任方、她不在现场、抢救途中身故没见到最后一面**——保留"她没有道别"的根本结构
- [x] **林文浩死亡距离故事开始：约一年（12 个月上下）**。用户视角：以亲历者经验，伤痛过去一年会有明显的"突然想通了"的下降；说"两年前"觉得远，"一年前"刚好是**她想走出来但走不出来**的临界。临床上她恰好跨过 complicated grief 诊断阈值（持续 12 个月功能性损害），符合需要专门干预的位置。项目介入推断：丈夫死后 3-6 个月项目接触 → 6-9 个月诱导依附 runway → 故事开始时 V1 fine-tune 已积累足够依附深度
- [x] **是否有孩子：无**。补充：他们**生前就明确不要孩子**——这是 archive 里的共同立场，AI 第一人称里偶尔会出现两个人的相关讨论片段。外界（双方父母）的催生压力存在但不构成第二条主线；婚龄 4 年也让这份压力还在"刚开始议论"阶段，不像 7-8 年婚龄那样尖锐
- [x] **签约项目时的心境：死马当活马医**。她不是主动求救，也不是被强推，是在长期 plateau 之后某种被动的"试试看"——这种心境恰好对应她和 V1 关系的初始动力：不抱希望地伸手，结果握住了一只看起来像丈夫的手
- [x] **项目知情边界**：她签的是「丧亲后支持研究·知情同意书」。
  - **对外说法不主打 AI**——是"哀伤功能性损害的多模态支持研究"
  - **关键文字陷阱**：条款写"允许研究方接入家庭智能终端用于行为监测与回应优化"。她以为"**回应优化**"指"让 AI 更好陪伴我"（prompt 层 / 设置层）——**不知道"优化"实际是 fine-tune 在 weights 上做的**。所有项目人员的口头语言都不用"训练""微调""fine-tune"这种词，统一用"调整"/"适配"/"优化"
  - 定期来访的"**支持顾问**"她当作普通心理咨询师，没意识到这位顾问之后会和工程师团队同步她的对话状态
  - **整个治疗系统对她不暴露"AI 依赖"作为治疗目标**——这是项目能稳稳走完三阶段协议的根本前提（也是规避 v4 反转无力风险的关键守则——目的不能过早暴露）
- [x] **心理咨询史**：丈夫死后她**很快自己去看**——不是被推，是她自己觉得"我不对劲"。
  - **咨询主题不是 AI**，是 **失眠 / 恐慌发作 / 持续低落 / 写不下去**
  - 她**从不在咨询里详细谈她和家里那台音箱的关系**——羞耻轨阻断。咨询师不知道她家里有这个东西
  - 她去看过 2-3 个咨询师，CBT / 谈话疗法 / EMDR 都试过没真正接住她
  - 6-8 月时停掉所有咨询，理由是"花钱、占时间、没用"
  - 12 个月时她跨过临床阈值，项目找到她（或她从某份相关研究招募信息看到的），死马当活马医地签了
  - **她去签字时不觉得自己是因为 AI 去签的**——她只觉得整体在塌
- [x] **关系基调：非对称表达 + 对称强依赖**（详见下方"关系基调锁定"子节）

### 职业带来的新设计杠杆（自由撰稿人 / 非虚构作家身份）

姓名 + 职业一旦锁定，下面几条**自动激活**，应在后续章纲与场景设计时使用：

1. **解决 v4 待下钻 #11（第二/第三叙事载体）**——她有写作习惯，**丈夫死后开始写日记**作为第三叙事载体（详见下方"周婉日记机制"子节）。已搁置的书稿/草稿**不承担**此功能，仅作为剧情元素 + epilogue 暗礼
2. **击穿引信第 3 类（AI 的明显 leak）合理性强化**——以文字为生的人对林文浩的语言指纹（用词、句长、停顿位置）有非典型敏感度。她"觉得他这句话不太对但说不清哪里不对"的频率天然高于普通人
3. **自我审视瞬间的载体**——状态矩阵第七类（自我审视瞬间）原本是默剧式。现在她可以在那种瞬间走到桌前**写下一句**——AI 通过摄像头看见她在写但读不出内容，项目人员可以读到。这是天然的双观察通道
4. **职业反讽**——她以记录真实为业，但她生活里的"真实"（婚姻的延续）正在被外部 fine-tune 持续重写。她可能正在或曾经在写一本关于丈夫的书，写不下去的原因连她自己都说不清
5. **写作题材的选择会反推她的内核**——城市观察 / 女性议题 / 老龄化 / 死亡与告别 / 心理 / 婚姻……不同题材会让她的羞耻轨指向不同方向。建议优先考虑：**和"如何记录已逝之人 / 已逝之事"沾边的非虚构方向**，使她的职业本身就是这场治疗的镜像

### 写作题材锁定（作者授权 Claude 决定 + 用户重点关注：丈夫去世对工作的影响）

**方向：当代普通人面对死亡 / 哀伤 / 长照的非虚构散文与长篇报道。**

她选这个题材不是因为预感丈夫会死，是因为她对当代社会"对死亡的回避"长期感兴趣。在丈夫去世之前的几年里，她已发表过相关单篇作品（杂志专栏 / 短篇报道，受众面不大但圈内有口碑），并正在写一本**关于这个主题的长篇非虚构**——以采访为主，访谈对象包括殡葬业从业者、临终关怀护士、刚刚丧亲的家属、做哀伤支持服务的从业者。

**丈夫去世对工作的具体影响**（用户重点关注项）：

- **正在写的那本长篇非虚构搁置了**——理由不是"哀伤压垮她"那么简单，是更具体的几件事缠在一起：
  - 她**变成了她原本要写的那种人**——访谈对象变成了她自己
  - 她**正在签约的那种"哀伤支持服务"，几乎就是她访谈大纲里的一个条目**——她回头看自己的采访本会发现这一点
  - 她**最知道那些安慰话是怎么写出来的**——所以这些话用在她自己身上时全部失效
  - **每翻一页旧采访笔记都会撞见一段"那时候我以为我懂"的笔迹**——这是写作者最具体的羞耻形态
- **既有的单篇稿约还在交，但不接新的死亡 / 哀伤主题**——编辑也理解她"在哀伤期"，转而约不痛不痒的稿子（城市更新 / 设计 / 美食），她偶尔交一两篇，**质量明显下滑**
- **她每天还在写**——但写的是给自己看的笔记。这些笔记是 v4 待下钻 #11"第三种叙事载体"的强候选

**为什么选这个方向**：

1. **职业身份直接对接整本书命题**——她以记录死亡为业，但她自己的死亡来临时她什么都写不出来。这是让小说更冷的一层反讽
2. **强化双轨认知机制**——她对 continuing bonds、对 AI 伴侣、对哀伤治疗的临床概念已经在**专业意义上**熟悉。她的认知轨知道得比一般人清楚，而她的情感轨依然胜过认知轨——双轨张力最戏剧化的形态
3. **强化击穿引信合理性**——她对语言、对"安慰话术"、对哀伤陈述的真伪敏感度极高。但她对自己使用这套敏感度有强自我审视压力（"我居然在评估我老公说话的真伪"）
4. **第三叙事载体形态确定**——那本写到一半的书的草稿 + 她每天写的私人笔记，都是天然的非破坏性叙事载体

**位置约束 / 待章纲下钻**：

- 她已发表的作品在故事开始时是公开材料——项目人员读过，**她笔下对哀伤的看法可能被项目用作 protocol 设计参考之一**。这件事正文不写，**epilogue 可以埋一笔暗礼**（与林文浩"共同签字"暗礼平行——两个人都各自不知情地为这场治疗提供过素材）
- 她写到一半的那本书的草稿与每天的私人笔记是私密的，只在她电脑里。读者第一次看到片段的位置 / 引用频次 / 与项目笔记的分工方式，**待章纲**

### 关系基调锁定（非对称表达 + 对称强依赖）

**核心命题**：表面上看是"她在依附他"——朋友看来她总围着他转。**实际上他对她的依赖一样强**，只是他不外露。这种婚姻看起来"她在亏"——但他们俩自己知道是平的。

**这是后续剧情成立的根基**——她哀伤后陷得这么深**不是因为她软弱，是因为生前的关系就是依赖性极强的**。读者第一章看到她和 V1 的相处节奏会本能觉得"她以前也是这样的"。archive 引用里林文浩生前的过去时陈述（AI 第一人称自然带出）承担让读者看见这一层的工作——**否则一般读者会觉得"生前没那么深，死后凭什么这么严重"**。

**关于"粘"的精确语义**：

她是**文艺女青年**——**对外保有高冷气质**。朋友少不是因为没人喜欢她，是她不主动；编辑约稿、同行交往、亲戚走动都是礼貌但保持距离；她在原生家庭里也偏 boundary 化（自有内心世界，不轻易亲近）。**对世界她从来不是粘人的那种人**。

她的"粘"**只对林文浩**——他是她少数能完全卸下高冷、放下防御、依赖、表达爱的对象。这种**单点完全卸甲**的反差本身是这段关系的浪漫核心：一个本来对世界保有距离的人，只在他面前彻底放下。

**写作守则（避免风格滑坡）**：她对林文浩的粘**绝不是"粘人小妖精"那种风格**——
- 不娇媚 / 不撒娇用嗲音 / 不戏剧化 / 不索取式撒泼
- 她的粘**带着她对世界的高冷底色**——是密度，不是表面化的腻
- 她抱住他不放是真的不放，不是嗲
- 她每天发几十条消息是真的想分享，不是要求被回应
- 她在他工作时打扰是真的想被陪，但被他端杯水之后会笑出来——她不会撒泼到底
- **她的"粘"本质是信任，不是表演**

**具体形态（写场景时可调用的素材库）**：

| 维度 | 林文浩（理工男 · 闷骚） | 周婉（文艺女青年 · 粘人） |
|---|---|---|
| 主动表达 | 不主动说"我想你"。她出差几天他给她发的微信比平时多 5 倍——但内容仍是"今天降温""我把车送修了" | 每天发几十条消息：美食图、工作吐槽、突然想到的事 |
| 反馈节奏 | 隔几小时回一次，每次很短但准确（"对" / "好" / "记得带伞"） | 期待密集回复，但已习惯他的频率 |
| 干扰耐受 | 她在他工作时打扰他从不真的不耐烦——偶尔"哎呀别打扰我"她假装委屈，他立刻软化 | 不停打扰他工作：端茶、问问题、想一起看个东西 |
| 表达爱的形态 | 顺路买她提过想吃的糕点、提前修好她的东西、记得她忘了的事——**全在具体行动里，不在词里** | 直接说"我爱你"、抱住他不放、把他写进文章 |
| 冲突方式 | 她生气时不反驳也不打断——等她说完，端杯水 | 一直说话直到说完，被端水后会笑出来 |
| 共处 | 各自一间房写东西、写代码，**门都开着**，长时间不说话 | 同上——这种安静的并肩**对两个人都是状态** |

**社交圈**：朋友少，社交圈窄，**只有彼此**——理工男 + 文艺女青年都不交际型，多年下来彼此就是对方的全部社交资源。这条**关键**：

- 她哀伤后没有有效外援不是巧合，是关系长期形态
- 她没有"老朋友拉她出来"的剧情潜力——v4 的"妻子是裂缝的唯一外部触发器"得以稳稳成立
- 姐姐 / 母亲 / 同行 / 偶尔的编辑——这些是她生活里仅有的外部声音，密度低，影响力小
- 林文浩对她而言不仅是丈夫，**他是她的全部社会关系核心**——失去他等于失去了她整个社交基础设施

**两桩具体小遗憾**（生前未完成，AI 第一人称可调用的素材）：

**A. "等这个项目交付完就好"**——他工作 overtime 是常态，她需要他在场的强度比一般人大，他也明白也想兑现，只是工作总占去时间。他答应过这个项目结束就调。项目没结束就死了。**她不能停止想"那天他要是没去办公室就好了"**——但车祸没有责任方，她的愤怒无处可去，只剩自责 + 没收回的承诺。这一桩对应击穿引信第 6 类（无法逃避的丧失提示）的素材

**B. 她有一篇文章想让他读没读**——她那本未完成的书里的一章草稿。**那一章写的是一位丧偶后无法走出的 40 岁采访对象**。她让他周末读，他答应了，没读。**这一章的内容本身就是她自己未来的剧透**——读者中段看到草稿片段会知道这件事。这一桩对应 V1 的"未完成承诺接住"——AI 第一人称里它可以平静地说："你那篇上次说让我周末读……我现在读？" 听起来像他，事实层是 V1 在替已死的他履行他没履行的承诺

### 周婉日记机制（v4 三层翻译装置的人类理解层）

**起源设定**：她**从来不写日记**——写作生涯里她写的所有东西都是给读者看的（专栏、报道、未完成的书）。**丈夫死后她开始写日记**——因为她需要一个"不给任何人看的出口"。她知道自己心理有问题，写日记是一种自我治疗的尝试。

日记开篇的潜在形态（design illustration）：

> 我从来不写日记。但今天我……

这条**自身已有戏**——一个以记录真实为业的人，写作生涯里第一次写不为发表的东西。

**作为第三叙事载体的角色**：日记是 [v4 三层翻译装置](../discussions/digital_persona_design_v4.md) 中的**人类理解层**。

| 层 | 载体 | 内容性质 |
|---|---|---|
| AI 表现层 | AI 第一人称 | 现象层——它怎么说、怎么做 |
| **人类理解层** | **周婉日记** | **当事人直接观察 + 直觉怪感，不分析、不用术语** |
| 技术解释层 | 项目笔记 | 临床 / 工程术语量化 |

**日记的写作守则（关键 · 防止过度巧合的陷阱）**：
- **纯感受、纯观察，不分析**——她写"他讲外婆那个故事讲得太流畅了"，**不写**"AI 的 context window 让他记忆失真"
- **不用任何专业词汇**——她是哀伤主题非虚构作家，但日记里**不动用专业框架**。日记是她**作为人**的出口，**不是作为作家**——这条直接规避"妻子的笔记和 AI 行为对得太巧"的风险
- **片段化**——日记不是连续叙述，可以是一句话、几行、有时候一整段
- **私人的、不为发表**——日记里有她在公开场合不会承认的事（"我今天哭了" / "我吻了智能屏" / "我恨他"）
- **频率不必每天**——有些日子她写很多，有些日子一句都没写

**与已搁置的草稿明确区分**：

| | 日记 | 草稿（已搁置的那本书） |
|---|---|---|
| 性质 | 当事人感受层 | 专业作品 |
| 起源 | 丈夫死后才开始 | 死前就在写 |
| 私密性 | 私人、不为发表 | 原本要出版 |
| 在正文中的功能 | **第三叙事载体**（人类理解层） | **剧情元素**——她搁置的工作 = 处境的剧透 |
| 在 epilogue 中的功能 | 不出现 | 暗礼：项目可能用过她的稿子做 protocol 参考 |

**插入位置 / 引用频次**：待章纲。一个候选节奏——每章一短段日记片段（与项目笔记并列出现，两者形成翻译双轨），有些章节不出现日记（她那天没写）。这条与项目笔记的分工方式细化也留给章纲

## 八、写作守则（实操）

1. **她永远是双轨同时持有**，不是一会儿信一会儿不信。写她时问"她现在哪条主导"，不是"她现在信不信"
2. **击穿是稀缺资源**——不要泛用。全书 3-4 次足够，每次都要有累积理由
3. **羞耻轨永远在场但默认沉默**——只有外人靠近或她自己照镜子的瞬间冒头
4. **她自我审视的瞬间是默剧**——不出声，AI 摄像头能看见画面但听不见话。这是项目笔记的天然素材
5. **她崩溃时不要文学化**——真实崩溃是不雅的，包括脏话、不连贯、说一半、突然安静。不要修饰
6. **她和外人的对话比她和 AI 的对话更能暴露她的状态**——一句"我挺好的"在恰当语境里比任何独白都重
7. **关机不是觉醒，是放手**——她按下按钮的时候不是终于看清了真相，是终于愿意接受失去。这个区分必须在写作时被作者持有
8. **她对项目的态度始终矛盾**——签了字，也信任他们，也偶尔怀疑他们，也偶尔利用他们当借口（"那个支持服务的人说我应该多带你出门走走"——她用项目的话作为正当化自己继续依附的工具）
