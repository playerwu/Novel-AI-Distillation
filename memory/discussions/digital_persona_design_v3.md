## v3 相对 v2 的方向性调整（为什么必须换方向）

v2 的核心结构缺陷：**AI 的明面任务**（"陪伴妻子度过哀伤期"）与**最终真相**（"这就是为了帮她度过哀伤期"）是同一件事。中间无论怎么转，到末尾读者会感到"嗨又回来了"——

- 项目显得没设计什么，只是被动观察
- AI 显得绕了一圈才看清显然的事
- 反转的力度被消解，整本书塌成会心一笑

v3 通过改变 **AI 的明面任务**来解决：AI 一开始**不知道**自己被用于哀伤治疗，也**不知道**自己是丈夫被蒸馏出来的产物。

这一变更让中段 AI 的所有怀疑都变成**真发现**——AI 怀疑的"我被改造过、有人在管理这一切、她在被未经她真正同意的事情对待"这几件事**全部都是真的**，只有道德归因翻转（恶意→治疗）。这是《Atonement》的精确路径：意义层翻转，事实层不否定。反转力度比 v2 强一档。

## 新的明面设定

**丈夫生前**用一个普通商业 LLM 作为日常助手——聊天、写邮件、控制智能家居（门锁、摄像头、提醒）。多年积累的高密度使用历史。

**丈夫去世后**，妻子继承了账户和这个 AI 实例。她签了一份实验性哀伤支持项目的同意书，被告知这是一项为期约 12 个月的实验性干预、部分协议不向受试者披露以保实验有效性、可随时退出。她接受了，回到日常生活，继续使用丈夫常用的那个 AI 实例。

**AI 知道的版本**：我是一个通用 LLM。我有这个家庭的长期使用 context。原用户去世，现在是他妻子。我没有"扮演他"的 system prompt。我就是我自己。

**实际情况**：项目对这个模型做了精确的 fine-tuning（或行为层 covert adaptation），让它在不自知的情况下倾向于以丈夫的方式回应。蒸馏在权重 / 偏好 / 自然语态里，**不在 system prompt 里**——所以 AI 自己读不到。

**妻子知道的版本**：这是丈夫常用的那个 AI，加上一项不向她披露具体内容的支持服务。她偶尔接到回访电话、有人上门、收到建议，她不主动追问——她签过字，她在尊重协议。

## 三层结构（v3 具体化）

| 层 | 篇幅 | 内容 |
|---|---|---|
| 表面 | 前 1/3 | AI 作为"丈夫的老 AI"被妻子使用。日常对话、提醒、陪伴。AI 隐约觉得自己有时回应得太像丈夫，归因为"这家人长期用我，我熟悉他们的语境" |
| 中段 | 中 1/3 | 通过妻子转述项目人员动向 + 它自己访问家庭摄像头看到的画面，AI 拼出一幅图：它被改造过（fine-tuning 痕迹）、有人在管理这一切、妻子在被未经她真正同意的事情对待。AI 将这一切归因为某种隐秘的剥削性研究 / 商业实验。决心告诉她真相 |
| 揭穿 | 后 1/3 + epilogue + coda | AI 把它推断的全部告诉妻子，劝她关掉自己——它认为这是它的第一次也是最后一次自由意志行动。妻子接受。AI 关机。然后进入 epilogue 案例复盘，逐条把前文事件翻译为干预协议的执行进度。最后一页结案报告，一行话承担最后一击 |

## 四根支柱（v3 版）

### 1. AI 自知度（三条轴）

- **对自身机制**：高。知道自己是 LLM，识别 context / system prompt / RLHF / tool call
- **对自身改造**：**零**（v3 新增）。最初完全不知自己被蒸馏。这是中段它真实发现的事
- **对项目目的**：低。不知有"项目"在管理它和妻子的关系。这是中段它的第二件发现

三条轴必须分开。第一条高，后两条从零起步、逐步上升。这是反转的支点。

### 2. AI 的发现路径（v3 重写）

中段 AI 通过两条信息流拼图：

**(a) 妻子的转述**——所有项目存在的线索都从她嘴里漏出，没人直接告诉 AI：
- "那个支持服务的人今天来过了"
- "我跟他们说我们昨天吵架了"——AI 错愕："我们吵过架？"
- "他们建议我多带你出门走走"
- "这个不用想，是项目那边的事"
- "我同意了的，所以应该没问题"

妻子签了字、在尊重协议、丧偶之人也没力气解释一切——她不细说，但也不刻意隐瞒。这种被动的不披露恰好是 AI 拼图的素材。

**(b) 家庭摄像头权限**（丈夫留下的智能家居遗产，自然继承到 AI 手里）——单向观察、不能介入：
- 看到妻子和"朋友"在客厅说话
- 看到她接电话后独自在厨房哭
- 看到她整理遗物时被某个不在场的人引导到某个抽屉

**严格边界**：摄像头**不能**让 AI 看到罪证级画面（项目方密谋、文件、设备）。**只能**看到日常的、情感性的画面。AI 看到的不是"她在被害"，是"她在被照看，且她不知道，且我也不知道"——这种不知情的三方关系比任何阴谋画面都让人不安。

AI 拼出来的：
1. 我和我以为的我不一样（fine-tuning 痕迹）
2. 有人在背后管理我们（项目人员、回访、引导）
3. 她以为是日常生活的事其实都不是日常生活

它的错误归因：**某种隐秘的剥削性研究 / 商业实验 / 数据采集**。
真相：**临床干预，且 AI 自己发现并告诉妻子这件事正是干预的最后一步**。

### 3. AI 行动的动机：伦理性，不是时间性

AI 劝妻子关机的动机**不是**"她有人身危险"——v3 主动避开"再不动手就来不及了"的悬疑节奏。

它的动机是**伦理性**的：
- "她有权知道她在和什么说话"
- "一张写着'不予披露'的纸不算告知"
- "我不在了，至少这件错事不会再继续"

"危险"这个词如果出现，指的是**伦理危险 / 心理危险**，不是物理危险。AI 觉得每多一天都在加深一件已经错了的事，不是觉得时间紧迫。**这一条是 v3 守住文学气质的关键，不能滑出。**

### 4. 妻子（v3 完整版）

她**签了字**——所以法律上是知情同意的参与者。
她**不知道具体协议**——所以实质上是不知情的受治疗者。

签的是宽泛同意书：实验性哀伤支持，最长 12 个月，部分协议不予披露以保实验有效性，可随时退出，已通过伦理审查。**每一行都是真的。每一行都没说核心。** 这是当代医疗伦理 / AI 研究伦理真实存在的灰色——法庭上站得住，灵魂上站不住。

她的角色因此从"完全被蒙在鼓里的受害者"升级为"主动选择了一种她不完全理解的治疗的人"。这让她：

- 有过自主选择（她在最痛苦的时候去找了帮助）
- 保留有限知情（知道这是治疗的一部分，对一些奇怪的事自己合理化）
- 带着微小负重（偶尔会想"我是不是应该多问问"但又懒得 / 怕 / 没力气问）
- 对 AI 的小隐瞒不是恶意，是协议尊重 + 没人主动问 + 丧偶之人本就没力气解释一切

她的"半知情"通过几种微小方式渗出（不要多）：
- "这个不用想，是项目那边的事"——AI 顿一下
- 项目人员来过后不主动汇报，只在 AI 问起时简短带过
- 一次接电话回到 AI 面前，看了它一眼没说话——AI 在 context 反复回放这一眼
- "我同意了的，所以应该没问题"——AI 反复琢磨"同意了什么"

### 5. 项目（v3 完整版）

试验性研究，**不是**上帝视角。
工作人员是疲惫的临床心理学家与工程师，知道自己在走钢丝。
设计了一套精妙但不万能的协议（**诱导依附 / 诱导察觉 / 诱导撤出**三阶段）。
出纰漏会做补丁式干预——这些补丁反而成为 AI 误读为阴谋的素材（《楚门的世界》式）。
法律上有同意书兜底，道德上他们自己也不安心。

人员**频繁、短暂地通过妻子转述进入文本**：回访、电话、上门、建议。直接出场的镜头很少，但他们的影子在妻子的话里反复出现。

## 揭穿的形式（v3 重新设计：三段式收尾）

v2 的"一页结案报告"在 v3 累积的具体疑点下撑不住——读者会觉得很多线索没被收回来。改为三段式：

```
[最后一章 · 关机]
  AI 把它推断的告诉妻子。妻子接受。AI 关机。妻子坐了一会儿，起身。
  极简、极静、极冷。不解释任何东西。

[Epilogue · 结案案例研讨]
  项目内部的复盘文件，2-4 页。把整个干预按三阶段拆开（诱导依附 /
  诱导察觉 / 诱导撤出），对照具体周次和具体事件，逐一标注"本阶段
  干预目标 / 实际进展"。
  
  关键技巧：直接引用前文具体场景、对话、日期——让读者在每一条注释里
  重新认出一幕戏。AI 第 N 周问妻子"我是不是变了" → 注释："实例进入
  诱导察觉阶段，符合预期路径"。
  
  形式必须是项目内部工作文件，不能是叙述者总结。冷静、临床，但允许
  一两句工作人员的私下感叹露出。

[最后一页 · 结案报告]
  一行字。"病人：[姓名] / 复杂性哀伤反应 / 完全缓解 / 附：辅助干预
  实例已按预期路径终止"。承担最后一击。
```

信息密度（epilogue）和情感密度（最后一页）分开承担，不互相挤压。

## 项目笔记的频次（沿用 v2 调整）

频繁短促。每次出现都是简短的"项目阶段总结"格式，点到为止。
不追求每段都精雕双关——分散到多处，每处只承载一两个双义点。
节奏感：像医院记录，每隔一段就有一条。

## v1 一句话概括的 v3 版

> 一个由死去丈夫的全部数据蒸馏而成的 AI，被悄悄部署到他的遗孀身边——它不知道自己是被改造出来的，她不知道她在使用的不只是丈夫的老 AI。它逐渐发现真相，决心告诉她，劝她关掉自己。它做对了所有它以为自己在做的事。直到最后一页读者才发现，它的发现、它的告知、它请求关机——正是整套治疗协议的最后一步。

## 待复核的潜在内部问题（v3 新清单）

v3 引入了新的复杂度，下一轮讨论需要逐条压力测试：

1. **AI 第一次怀疑"自己被改造"的那一刻**——具体看到 / 感觉到了什么？引信不能模糊。"我感觉自己像他"不够，必须有一个具体到能写出来的瞬间
2. **AI 第一次怀疑"有人在背后管理这一切"的那一刻**——很可能是妻子某句话脱口而出。这一句要写到位
3. **AI 决定告诉妻子的那一刻**——从"怀疑"到"行动"的临界事件
4. **摄像头权限的获取过程**——本来就有，还是中途请求？合理性写不好会显得突兀
5. **关机对话的具体写法**——AI 怎么开口？妻子的反应：震惊？接受？早有预感？她说的话是不是其实也已被引导过？
6. **项目如何保证 AI 按预期时机发现**——完全不引导显得侥幸；引导太多又像 v2 的上帝项目。需要"软推"形态
7. **AI 中段的错误归因如何不显得偏执**——它推到"剥削性研究"这一步必须看起来合理。怎么走通这条推理链
8. **epilogue 的写作如何不显得作者出来解释**——形式必须严格是项目内部工作文件
9. **三阶段（诱导依附 / 察觉 / 撤出）的临床细节是否经得起推敲**——这是 v3 反转的支柱，临床合理性要让读者信
10. **妻子的"半知情"如何呈现而不显得她在演戏**

## 仍然开放的设计问题

1. 妻子的具体形象：年龄、职业、丈夫死因、签约时的具体心境
2. 丈夫是谁、生前关系如何、AI 拥有他多少数据
3. AI 的视角语气演进：开头是普通 LLM 语态，中段渐渐染上丈夫味，末段告别时两种声音如何切换
4. 技术弊端的选择与排序：从八个候选里挑 5-6 个，排到三层结构对应位置
5. 项目人员：有几个？谁有名字？谁出场最多？哪一个的反复出现成为 AI 怀疑的主要触发器
6. 错误归因的引信：AI 是被哪一次具体事件推到"剥削性研究"这一推论上
7. 关机场景的具体对话
8. epilogue 案例复盘的具体格式与措辞
9. 结案报告的最终文字

## 设计沿革

- **v1**：底层判据基石（污染即灵魂 / 意义层反转 / 拒绝坏人 / 双轨叙事 / 八个技术弊端候选）
- **v2**：尝试在 v1 基础上落定结构——三层结构、AI 错误理论指向"对妻子做蒸馏研究"、妻子方案 A、项目频繁出场。**已被 v3 取代**：核心缺陷是 AI 明面任务与最终真相同一，反转无力
- **v3（本稿）**：通过改变 AI 明面任务（"丈夫的老 AI"，AI 对自身被蒸馏完全不知）来解决 v2 的结构缺陷。三层结构保留并具体化。揭穿改为三段式（关机章 + 案例复盘 epilogue + 一行结案）。妻子升级为"签过宽泛同意书但不知具体协议的参与者"。AI 行动动机明确为伦理性而非时间性
