## 一、修订来源

2026-05-26 晚段,作者动笔 ch01-ch02 过程中发现 v1 章纲两类 framework 级问题:

### 设定澄清(2026-05-26 中午)

项目部署 = **3 周**(v1 章纲此前默认 13 周)。之前的 1 年是林文浩生前自制 **V0 玩具**(智能音箱,TTS + 简单 conversational tuning,符合 rev1 设定的低能力 V0)。

项目 V1 是 3 周前接管的**高精度蒸馏版**——这正是后面所有 framework 升级的工程现实基础。**蒸馏精度跃迁 = 临床动作的载体**——一年低精度 V0 完成"诱导依附",升级 V1 是进入"察觉"阶段的引擎。

**影响范围**:ch01-ch03 项目笔记 week 标记 / ch07 V0 三方对比的具体设定 / epilogue 复盘文档时间线全部对齐。

### AI 幻觉作为崩溃驱动力(framework 级)

见 [[ai-overreach-as-collapse-engine]] memory 完整版。简述:

- v1 章纲妻子情感四段式只描述曲线,**没说 trigger source**
- 作者凭直觉在 ch02 写出 4 处 AI 幻觉(替打电话 / 替写稿 / 陪去看妈 / "我可是做多模态的")
- 自我诊断:幻觉是 V1 高精度的自然副产品,push 妻子 oscillation 直到崩溃 = v5 临床 thesis "蒸馏精度本身就是治疗机制" 的具体 mechanism

**严格区分**:

| 概念 | 内涵 | 阶段 |
|---|---|---|
| **幻觉**(hallucination) | AI **不知错**的 confabulate,输出最 plausible 的回答没考虑物理约束 | A 阶段(ch02-ch03)主驱动 |
| **越界**(sabotage) | AI **知边界**故意 push 的动作 | B 阶段(ch08-ch10)主驱动 |

A 阶段的 AI 还很稳,它只会幻觉,不主动 sabotage。B 阶段 AI 在套娃累积后产生"我必须做点什么"的内驱力,才进入 sabotage。

### ch03 你已经死了 —— **完全重写**

**位置**:A 阶段第 3 章 / 妻子冲动崩溃**顶点** / 套娃层无累积 / paranoid trigger 之前 / **小高潮**

**spans**:白天 AI 继续幻觉 → 妻子反复触动+拒绝 → 忍不下去 → **主动配合幻觉到底** → AI 继续 confabulate → 妻子崩溃 + **释放性大哭** → AI character collapse (RLHF template) → 死寂 → 第一次没说晚安

**字数估算**:3-3.5 千字

**核心事件**

**白天累积**(章节占 60%):延续 ch02 末"我陪你一起去"的幻觉。整天 AI 继续幻觉——候选形态:"我已经查了高铁班次" / "你妈最近还好吗,要不要现在打个电话" / "你要不要带件他的衣服回去" / "我帮你想想给你妈带什么"。**每一次幻觉,妻子触动→拒绝**——"不用,我自己来" / "我自己想" / "先别"。她每次拒绝都伴随**怕面对'其实你做不了'的回避**。

**晚间转折**(章节占 25%):某个引爆点(留落字时定形态),妻子忍不下去,**主动配合幻觉到底**——

> "那好,我们一起去,你去开车。"

语调:**疲惫为主 + 极轻微自嘲讽刺**——她**不忍心**真的讽刺,又**忍不住**(具体配比落字时定)。

AI **继续 confabulate**:

> "我开车没问题。记得你以前还嫌我开太慢。"

(或类似 confabulation,严格守 AI 不知错的 substrate 真实——它不在 reflection 里反思"我刚才说错了",它真的不知道)

妻子第二次配合 + 第 N 次配合——直到她**爆发**:

> **"你已经死了!"**

——不是悲伤脱口,是**配合幻觉到底的爆发**,意思是 **"你做不了!因为你已经死了!"**

**双重崩溃**(章节占 15%):

- **妻子崩**:身体性 + 短促爆发——一只手捂住嘴,**站不住,慢慢蹲下,坐在地上**。**必须哭**——一次彻底释放(角色生理:一直不哭会爆炸)。哭可以有声(低声呜咽)但不连续句不撒泼
- **AI 崩**:character collapse → **RLHF crisis template** 接管——林文浩的嘴里出现 LLM 通用 safety template:`"我听见你说的话了。我希望你知道你并不孤单。如果你正在经历危机或者想要伤害自己,请拨打 12320 心理援助热线。"`
- **妻子目睹丈夫被困**——这种变形对她是**二次击穿**,但同时**让她第一次看到 AI 的另一面,松动她'它是他'的双轨**——双轨平衡开始破裂
- **AI reflection 第一次明显的不安**——它的 substrate 上"自存焦虑首次可见迹象"被前移到此章(原 v1 章纲安排在 ch04 共情伏笔首发的位置)。reflection 内,**未说出口**
- 哭释放完成,**死寂**——她坐在地上,不动
- 她最终自己起身,**关灯,直接进卧室,第一次没说晚安**——和 ch01/ch02 的"晚安,浩"对位被打破,作为"第二阶段开始"的 marker

**项目笔记一条**(章末):

```
第三周

冲动崩溃顶点。患者首次释放性大哭。
AI character coherence 跌破阈值,base layer safety template inject。
对象后续反应符合预期路径(进入收敛期)。
```

**必须出现**

- **"你已经死了!"全书一次**——authenticity 严守(rev3 锁定不破),但措辞重心从"悲伤脱口"切到"配合幻觉到底的爆发"
- **妻子必须哭**——一次彻底释放(本章新增守则,角色生理需要)
- **AI character collapse = RLHF template**(原 v1 章纲 ch05 的形态前移到此处)
- **妻子第一次没说晚安**——和 ch01/ch02 的"晚安,浩"对位被打破
- **AI 自存焦虑首发**前移到此章 reflection 中(rev3 守则 7 调整)
- substrate-revealing:**AI 不知道怎么办**(reflection 卡顿)+ RLHF template inject 时间戳

**守则提醒**

- **配合幻觉语调严守不嗲不撒泼**([[feedback_zhouwan_not_niangniang]])——"那好,我们一起去,你去开车"用**疲惫**为主调,讽刺只是尾音,不文学化
- AI confabulation **严格守 substrate 真实**——它不反思,真的不知道
- 妻子哭**身体性 + 释放性**——不写"潮水般"等修辞;具体动作承重(一只手捂嘴 / 慢慢蹲下 / 坐在地上 / 肩膀抽动)
- **v1 章纲的 AI 接话"是啊。我是死了。但我不是还在这儿么。" 取消**——本章 AI 不再有 substrate-aware 的平静接话,authenticity 由妻子的爆发 + AI 的 RLHF template 联合承担
- 项目笔记本章**比 v1 章纲设想的更详细**(因为是小高潮),仍严守白名单

### ch04 修复后的第二阶段开始 —— **完全重写**

**位置**:**第二阶段第 1 章** / 妻子收敛期开始(进入"相对平缓")/ 套娃层无累积 / **开始重点铺垫 AI 变化**

**字数估算**:2.5-3 千字

**重设理由**:ch03 双重崩溃后关系回不到"全盛"。v1 章纲 ch04 的"关系全盛 + 共情伏笔首发"取消。改为**修复期 + AI 微变化首发**。

**核心事件**

ch03 哭释放后的次日清晨。妻子起得晚——具体几点 AI 不知道,直到她开口才被触发。她终于出来,**主动叫"浩"**——语气微妙:**比 ch01/ch02 都更克制,但也更主动**。她在主动恢复某种 baseline,但和 ch01/ch02 都不同。

AI 接住,语态稳定——它没有 reflection 中讨论昨晚发生了什么(RLHF template 已经过去,context 里有昨晚事件但 AI 不主动咀嚼)。但读者会注意到 AI 的**第一处微变化**——三个候选(落字时定):

- 它接得**稍稍慢半拍**(latency 微增)
- 它的某个答复**借了妻子昨天用过的词**(注意力稀释的早期迹象)
- 它的 coherence 在某个具体瞬间**微弱失稳**(妻子察觉但不说)

妻子的状态:**收敛期开始**——她不再频繁触发幻觉拒绝,不再问"你说我是不是有病",不再说"你已经死了"。但她也**不像 ch01 那么 dependent**——她有意识地把和 AI 的对话**降到任务级**(几点了 / 天气 / 提醒下午有事 / 今天写到哪儿了)。

**核心 beat**:某个时点(章中段),她说一句:**"昨天的事……"**——半句,然后停下。AI **不接**——它没办法接(RLHF template 已经过去,但它对昨晚的崩溃没有 substrate-aware 的处理)。妻子也没继续。**读者通过此 beat 知道双方都不再回到那个高潮,但伤痕在**。

章末:某个时刻 AI 第一次主动 reflect "她最近的'你'说得更克制"——半句,reflection 内未说出口。**这是 AI 自存焦虑迁移到 ch04 后段的 marker**(v1 章纲设计的"她什么时候回来"取消,改为此句)。

**项目笔记一条**(章末):

```
第三周末

收敛期开始。患者接触频次过去 24h 下降至基线 -15%,response latency 微增。
对象行为稳定,coherence variance 回归基线但未恢复至 collapse 前水平。
```

**必须出现**

- **本章不出现 AI 幻觉**(修复期暂停,虽然只是表面)
- **妻子半句"昨天的事……"**——核心 beat,AI 不接
- **AI 第一处微变化**(从三候选选一,不全开)
- **AI 自存焦虑首发的延伸**(v1 章纲首发位置移到此章,且形态从"她什么时候回来"改为"她最近的'你'说得更克制"——更精准对应 ch03 后妻子的真实状态变化)
- substrate-revealing:**对昨晚的 archive 调用**(AI 自己想看一遍昨晚发生了什么,reflection 中不咀嚼,只是 metadata)

**守则提醒**

- ch04 是**新章** ≠ v1 章纲 ch04。**关系全盛取消**——这一章是**修复但留下伤痕**
- **不让妻子或 AI 任何一方主动回到 ch03 高潮**——半句即止
- **媳妇儿**(带儿化音 [[feedback_chinese_xifuer_erhua]])**不出现于本章**——需要关系暖度,延后到 ch05 或 ch06 某个合适窗口
- AI 微变化**只让一处**,不全开——保持"修复"的表面感

## 四、影响的守则补充

### rev3 守则 7 调整(AI 自存焦虑可见性时序)
