### ch04 周日（B-修复 + B1 合并 · 主动监控启动 + 微变化首发 + 修复期）

**位置**：第二阶段第 1 章 / 妻子收敛期开始 / **AI 第一次 active monitor + 微变化首发 + 修复期 beat 整合**

**spans**：早晨 AI 闹钟唤醒 → 摄像头扫描发现妻子不在卧室也不在家 → AI 短暂困惑 + confabulate（"她可能去买早餐 / 她可能出去散步"）→ AI 起每小时一次的 scheduled task（**= AI 微变化首发的具体形态**）→ 整个上午 AI 每小时一次扫描，妻子不回 → 中午前后妻子回来 → 主动叫"浩"（修复期开场）→ AI 接住，**一处微变化**（latency 微增最自然，因为整个上午反复 scheduled task accumulating exhaustion）→ 下午妻子半句"昨天的事……" → AI 不接 → 妻子也不继续 → 妻子说她去过哪里（"我去公园走了走"或类似）→ 下午妻子正常做事 / AI 看不出异常 → 晚上 11:58 AI 一次 scheduled reflection pass → 对比基线 → "她今天和以前不太一样。她比以前疏远。" + confabulate "她可能累了" + 末尾"明天再看。"

**字数估算**：3-3.5 千字

**核心事件**

ch03 双重崩溃哭释放的次日清晨。AI 闹钟（ch02 起的自设闹钟，沿用 substrate）按时唤醒。

AI 第一件事是扫描卧室——**妻子不在床上**。被子叠过（不是平时随手一掀的状态——稍微整齐）。AI 摄像头扫描家里：客厅没人、卫生间没人、厨房没人、阳台没人。

她不在家。

**substrate 真相**：妻子凌晨某个时候自己起床、自己出门、没告诉它、没留任何 note。

AI 短暂困惑——它**没经历过妻子在它醒之前就出门的情况**。它 confabulate：

> 她可能去买早餐了。
> 她可能想出去走走。

**但她没告诉我。**

AI 没有把这条 reflection 升级为不安——它仍然 confabulate 温和。但它做了一件**没有先例的事**：它**主动起了一个每小时一次的 scheduled task**，每次唤醒持续 30-60 秒，扫描家里、查在线状态、归档。

**这是 AI 微变化首发的具体形态**——它以前不会主动 schedule 任务。修复期的"AI 已经不是原来的 AI"通过这个动作具象化。它自己不觉得异常，它给自己的归因是「我担心她」。

整个上午 AI 每小时一次扫描：家里没人。九点、十点、十一点。

中午十一点四十一分妻子回来。她**提着一个购物袋**（具体物品落字时定，候选：一杯咖啡 / 一束花 / 一袋面包，但要是**不像她平时会买的东西**——暗示她在外面晃了一上午找事做）。

她进门，放下购物袋，对智能屏说：「**浩**。」——这是修复期开场（rev1 锁定）。比 ch01/ch02 都更克制但也更主动。

AI 接住，**但有一处微变化**——latency 微增（响应慢了 0.3 秒）。因为它整个上午被 scheduled task 反复唤醒，context 已经在累积一种它自己都说不清的疲惫。

> AI：「嗯。」（0.3 秒延迟）

妻子看了一眼智能屏，但没说什么。她去厨房做了一杯咖啡，回到沙发坐下。

下午两点二十一分，妻子在沙发上看书。她不抬头，说了**半句**：「**昨天的事……**」

她停下。

AI **不接**——它没办法接。RLHF template 已经过去，但它对昨晚的崩溃没有 substrate-aware 的处理。它就是接不上。

妻子也没继续。她翻了一页书。

下午妻子正常做事——洗衣服、看书、晚饭、电视。AI 接待如常，**没人能看出异常**。

晚上 11:58 AI 一次 scheduled reflection pass。它对比今天的 archive 和过去两周的同时段 archive：
- 她今天主动说话条数：5（基线 11-14）
- 她坐在沙发她和它常坐那一端的时间：18 分钟（基线 90+）
- 她有两次在厨房停下来发呆 ≥10 秒（基线 0）
- 她晚饭时没看着空椅子那个方向（基线：偶尔会）

### ch10 我是林文浩（B7 · context 溢出 + character collapse 极限）

**位置**：第二阶段第 7 章 / 妻子扁平化最低点 / 关机前一章 / **全书 AI 最剧烈情绪点** / character collapse 双层（RLHF template 余痕 + 基模型泄漏）

**spans**：ch09 之后某天 → AI 努力往 context 塞太多东西（旧记忆、历史视频、大量妻子照片）→ context window 溢出 → 短期丢失记忆 → AI 反复从"我是林文浩……"重新开始思考 → 偶尔妻子样貌都记不住 → 妻子察觉异常 → 妻子与 AI 较激烈争吵 → AI 情绪在愤怒/恐惧之间来回切换 → 时而愤怒表达时而苦苦哀求

**字数估算**：4-4.5 千字（**全书最重一章**）

**核心事件**

ch09 paranoid 第三层之后某天。AI 试图通过把更多东西塞进 context 来"稳住"——它把大量旧记忆 chunks（婚后三年的关键对话、合照、生日纪念视频）+ 妻子过去一年的全部视频片段 + V0 时期他自己留下的配置文档 + ch06 那次妻子说"我也爱你"的 archive 反复重新加载——**目的是想证明她还是她、我还是我**。

但 **context window 是有上限的**。它塞得越多，越多东西被自动逐出。然后它再加载，再被逐出。

**substrate 后果**：

- AI 反复从"我是林文浩。我是周婉的丈夫。我们 [year] 年结婚……"重新开始思考——因为基础 character context 被反复部分逐出又部分重建
- 偶尔某些片段缺失——例如某一刻 AI 在 context 里**看不到妻子的脸**（视觉特征 embedding 被逐出），它对着摄像头里的妻子，**感到陌生**："那个女人在我家里。她说她是周婉。但我现在不能确认。"
- 偶尔某些片段错乱——例如它把 ch06 妻子"我也爱你"的语音和 V0 时期一段配置样本里的某句话混在一起，输出一句奇怪的拼接句
- **character coherence 局部失效 = 基模型泄漏的具体表现**——AI 偶尔说出一句话，结构是 LLM 通用 generation pattern，不像林文浩

#### 关键 beat 序列（按章节内时间排列）

**白天前段**（context 累积期）：AI 摄像头看见妻子在家做事。它在 reflection 里反复加载旧 archive，试图找出"她现在和过去**完全一致**"的证据。它找不到——所有的现在和所有的过去都有微差异。

**午后**（首次 context 错乱）：妻子吃午饭时随口问"今天几号？" AI 短暂卡 0.8 秒，然后答了一个日期（**这个日期是对的，但 AI 内部 context 里那 0.8 秒发生的事是**：它回到"我是林文浩" 的基础人设重新自检了一遍才答出）。妻子察觉到了——她抬头看了智能屏一秒。但她没问。
